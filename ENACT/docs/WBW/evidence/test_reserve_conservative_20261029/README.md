## 1. 先修正两处论证错误（本轮之前我写错的）

| 我此前的说法 | 实际 | 修正后表述 |
|---|---|---|
| 501 的 dvl 在 F230–300 **单调上升**，故不存在同高度帧对 | 该区间有 **4 次回落**，且 f147 与 f275 的 dvl 为 0.35625714 / 0.35633340（差 7.6e-5） | 近等 DVL 帧**确实存在** |
| 用同高度帧对消去相机运动，可判定离底 | — | **方法不成立**：同 DVL 只说明离底高度相同，**不保证相机位置、朝向与机械臂姿态相同**。差分法的前提缺失，不是"在这条 episode 上失效"，而是**判据本身不可用** |
| 缺标定 ⇒ 所有 pick 的 lift 均不可证 | 目前只确认 501 未通过、10 条均未完成该判据验收 | 本版表述改为"**暂不纳入未确认的 Lifted**"，不推广为"pick 的 lift 不可证" |

保留的结论只有一条：**在现有 ego 单目、无内参、无深度、近无纹理沙面的材料下，尚无一例 lift 取得阳性验收。**

## 2. 本版的 scope 变更

| 谓词 | pick（8 条） | transfer（2 条） | 理由 |
|---|---|---|---|
| `Lifted` | 移出 scope | 移出 scope | 未取得阳性验收，不纳入未确认状态 |
| `OnSeabed` | **保留** | **移出 scope** | pick 的 start/approach/grasp 三帧支撑可见；transfer 的 at_box 处支撑不可判（若保留会在 at_box 处隐含"离底"） |
| `InGripper` | 保留 | 保留 | 夹爪闭合 + 物体随末端可见 |
| `NextTo` | 保留 | 保留 | approach 帧可判 |
| `NearBox` | — | 保留，**独立验收** | 不隐含 Lifted；at_box 需单独裁决 |

关键：**at_box 绝不隐含已离底**。为此 transfer 的 at_box 帧只保留 `InGripper=true`、`NextTo=false`、`NearBox=true`，删去 `OnSeabed=false` 与 `Lifted=true`——否则"离底"会从 at_box 偷偷回来。

## 4. 这个方案的代价（必须写进论文限制）

1. **判别力下降**：8/10 题变成 2 选 1，随机水平 0.5。模型之间哪怕差异很大，在 8 条 L3 上也很难拉开——按二项分布，8 题全对与 7 题对之间的差距不足以支撑结论。
2. **文本基线更强**：L3 的 forward 题只有两个转移，动作文本几乎直给顺序；图像条件的边际价值进一步缩小，A 与 C 的区分度可能比 L4/L5 更弱。
3. **动力学维度丢失**：整套 test 不再包含"物体离地"这一状态，只剩接近、夹持与（transfer）到箱。
