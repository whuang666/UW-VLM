## 4. 两个必须记录的新发现

### 4.1 修订 onset 对 transfer 会抓到"运输段"而非"抬升段"

1378 在合规窗口内取 f290（onset+50，dvl 0.475），但画面中机器人已开始**朝绿箱移动并下降**，圆柱比 f250 更贴近沙面。即：修订 onset 把"开始向箱子移动"误当上升起点。

因此**不能把修订 onset 直接套到 L=5 transfer 上**。对 transfer，onset 应以"物体最低点离开沙面"为判据，而非机器人离底高度。

### 4.2 1378 的正确降级路径

| 方案 | 做法 | 评价 |
|---|---|---|
| ❌ 去掉 at_box | 保留有争议的 lift | 不解决问题（v1 的错误建议） |
| ✅ **删 lift、保留 at_box** | start → approach → grasp → at_box，构成 **L=4** | 用已确认的 at_box 替代未确认的 lift；但必须重新验收 grasp→at_box 转移的 ego 可判性（跨过抬升段） |
| ✅ 剔除 | 不进 test | 若上述转移不可判，则剔除 |
