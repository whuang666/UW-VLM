# 每日项目记录

每天运行维护任务后，在 `docs/daily/YYYY-MM-DD.md` 追加一段记录，日期采用 `Asia/Shanghai`。同一天多次运行追加时间戳，不覆盖旧段落。

推荐字段：

```markdown
# YYYY-MM-DD

## HH:mm 本次维护

- 检查范围：开始时的 HEAD、分支、远端与工作区状态。
- 本次变化：做了什么、为什么、涉及哪些文件；区分新代码、已有未提交工作和新增实验产物。
- 实验状态：输入／数据／评分版本、run 路径、题量、结果、限制；未运行写明未运行。
- 验证：实际执行的命令、退出码与通过／失败／跳过原因。
- Git：将随本记录提交的内容、推送目标、已确认的前序推送状态。
- 未解决事项：进行中的工作、冲突、缺失依赖及下一步。
```

提交本条记录时，当前提交的 SHA 尚未生成，不写虚构的“本次 SHA”或提前声称已推送。本次 SHA 与远端核验结果放在 agent 的最终回复中，下一次维护可补充到记录。即使当天无业务变化，也记录“无实质变化”和实际检查结果，再提交这条记录。
